# HCI Multimedia Flutter Project

A simple Flutter app created for the HCI Multimedia task.

## Features

- Home page
- Courses page
- Gallery page
- Profile page
- Clean UI using Flutter basics
- Bottom navigation bar
- Cards, buttons, lists, and simple page layout

## How to Run

```bash
flutter pub get
flutter run
```
